# Cross-Site Scripting (XSS)

Cross-Site Scripting testing checklist: stored/reflected/DOM/blind XSS discovery, polyglot payloads, CSP bypass, XSS filter bypass, event handler injection, DOM clobbering, mutation XSS, and impact escalation (session hijack, phishing, keylogging). Use for web app XSS testing and bug bounty. Use when performing authorized red-team, pentest, or research work involving xss.

## When to use

Use when performing authorized red-team, pentest, or research work involving xss.
