# File Upload Vulnerabilities

File upload vulnerability checklist: MIME type bypass, extension bypass, magic byte manipulation, path traversal in filenames, stored XSS via SVG/HTML upload, server-side processing attacks, and race conditions. Use for assessing file upload endpoints in web app pentests or bug bounty. Use when performing authorized red-team, pentest, or research work involving file upload.

## When to use

Use when performing authorized red-team, pentest, or research work involving file upload.
