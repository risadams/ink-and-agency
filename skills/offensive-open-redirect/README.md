# Open Redirect Vulnerabilities

Open redirect vulnerability checklist: parameter identification, bypass techniques (URL encoding, double slashes, CRLF injection, protocol handlers), chaining with OAuth/SSRF, and impact escalation paths. Use for web app testing and bug bounty open redirect discovery. Use when performing authorized red-team, pentest, or research work involving open redirect.

## When to use

Use when performing authorized red-team, pentest, or research work involving open redirect.
