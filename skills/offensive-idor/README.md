# Insecure Direct Object References (IDOR)

IDOR (Insecure Direct Object Reference) testing checklist: object ID enumeration, horizontal/vertical privilege escalation, GUID predictability, indirect references via hashes, chained IDOR, and API endpoint IDOR. Use for web app pentests and bug bounty IDOR discovery. Use when performing authorized red-team, pentest, or research work involving idor.

## When to use

Use when performing authorized red-team, pentest, or research work involving idor.
